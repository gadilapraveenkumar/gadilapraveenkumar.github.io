# Gadila Praveen Kumar — Portfolio

A responsive, dark, single-page portfolio inspired by the information architecture and visual feel of the referenced Thangaraj Kumaraswamy portfolio: hero, about, technical skills, key projects, experience timeline, education and contact.

## Included

- `index.html` — portfolio page
- `style.css` — responsive dark UI
- `script.js` — navigation, active-section state and scroll progress
- `assets/Gadila_Praveen_Kumar_Resume.pdf` — uploaded resume

## Run locally

No build step is required.

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `praveen-kumar-portfolio`.
2. Upload all files/folders from this project.
3. In GitHub: **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`.
5. Save. GitHub will publish the site.

## Personal links

The resume supplied in this project lists LinkedIn and GitHub but does not include their URLs. Add the real URLs to the contact/navigation area after you provide them. No URLs were invented.
